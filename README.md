# AI Document Intelligence System

AI-powered Document Analysis platform using
LLMs, RAG, FastAPI, Streamlit, and ChromaDB.

## Features

- PDF Processing
- DOCX Processing
- Text Extraction
- AI Summarization
- RAG Question Answering
- Semantic Search
- Insight Generation

## Tech Stack

- Python
- Streamlit
- FastAPI
- ChromaDB
- LangChain
- Gemini/OpenAI
